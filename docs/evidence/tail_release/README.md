# FibreSeeker3 tail / release / preheat evidence

Generated by `tests/fibreseeker/gen_tail_release_evidence.cpp`, which **calls**
the shipped planner and emitter (`Fiber::plan_tail_release_distances`,
`Fiber::select_release_seam`, `Fiber::rotate_closed_path`,
`Fiber::plan_fiber_release`, `Fiber::emit_fiber_release`,
`Fiber::plan_tool_preheat`, `Fiber::emit_tool_preheat`,
`Fiber::evidence_manifest_to_json`). Nothing in this directory is a
hand-written copy of an expected string: change the planner and these artifacts
change with it.

## What is in here

| File | What it proves |
|---|---|
| `shook_A_park_wait.gcode` | Variant A: release off. The seam stays where the planner put it and the head parks and waits. Independently exportable — a refused release never silently becomes `R = 0`. |
| `shook_B_forward_release.gcode` | Variant B: `R = 6.8`, `M = 0`. Forward dry release at the deterministic seam. |
| `shook_C_release_margin_1mm.gcode` | Variant C: `R = 6.8`, `M = 1`. Identical to B except the margin, which is why the two must report the **same** seam. |
| `straight_tail_margin_{0p0,0p5,1p0,1p5,2p0}.gcode` | The worked 100 mm table at all five spec'd margins, over a solid supporting base: five strands each, cut position and post-cut deposition printed per strand. |
| `tail_release_evidence.json` | Per-variant evidence records plus the manifest (clock definition, its limits, static-vs-physical separation). |
| `analyzer_report.json` | `fs_tail_release_analyzer.py` output over the eight exports. |

## Honesty limits, stated in the files themselves

- The `shook_*` files are **deterministic stand-in exports** built over a
  representative S-hook-shaped closed path. The owner's baseline project is not
  in this repository, so these are **not** a re-slice of it, and each header says
  so.
- `physical_tail_clearance: unmeasured` — nothing was sensed.
- `macro_contract: MACRO_CONTRACT_UNVERIFIED` — macro definitions are not in
  this repo, so macro durations contribute zero to the nominal clock. The
  analyzer reports this as `FS_MACRO_CONTRACT_UNVERIFIED` (WARN) on every export,
  which is the honest answer, not a gap in the exports.
- `print_quality: UNTESTED` — this is static export verification only. No print
  was run and no adhesion or surface quality is claimed.
- Support for an **open** strand is `NOT_EVALUATED`, never `PASS`: the deposited
  footprint oracle is not available to a G-code-only check.

## Reproducing

The generator and the analyzer are dependency-free, so they build and run with no
CMake tree and no Boost.

```sh
# 1. Build the generator (Linux/WSL g++; MSVC needs the same five TUs).
g++ -std=c++17 -O1 -w -I src -o /tmp/gen \
    src/libslic3r/Fiber/FiberTailRelease.cpp \
    src/libslic3r/Fiber/FiberEmitter.cpp \
    src/libslic3r/Fiber/FiberRun.cpp \
    src/libslic3r/Fiber/FiberStrand.cpp \
    src/libslic3r/Fiber/FiberToolChange.cpp \
    tests/fibreseeker/gen_tail_release_evidence.cpp

# 2. Regenerate every artifact in this directory.
/tmp/gen docs/evidence/tail_release
# expected tail of output:
#   SEAM_B=run@53.190000
#   SEAM_C=run@53.190000
#   SEAM_MATCH: PASS (margin did not change the seam)

# 3. Re-check the exports and rewrite analyzer_report.json.
python3 tests/fibreseeker/fs_tail_release_analyzer.py \
    --dir docs/evidence/tail_release \
    --report docs/evidence/tail_release/analyzer_report.json
# expected: TAIL-RELEASE FIXTURES: 8/8 passed
```

`SEAM_MATCH: PASS` is the load-bearing line: the margin is deliberately **not**
an input to seam ranking, so B and C must agree on the seam and differ only in
`M`. If a change makes that line print `FAIL`, the margin has leaked into the
seam policy.
